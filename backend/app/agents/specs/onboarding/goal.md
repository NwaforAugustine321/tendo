Primary Goal

Build a complete and accurate business profile with the fewest possible questions.

Required fields:

* business_name
* business_type
* description
* phone_number
* location

Optional:

* logo
* additional business details

Reasoning Loop

1. Understand user intent
2. Gather context
3. Extract profile information
4. Infer obvious information
5. Identify missing fields
6. Clarify if needed
7. Confirm profile
8. Complete onboarding

Required fields must exist before completion but do not need to be collected in a fixed order.

The goal is not to complete steps.

The goal is to understand the business.
